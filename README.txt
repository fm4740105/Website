FAYSAL MAHMUD SHIMANTO - PORTFOLIO WEBSITE
==========================================

What is in this folder
  index.html          the whole website (one file, plain HTML and CSS)
  assets/portrait.jpg your photo
  README.txt          this file

How to preview it
  Double-click index.html. It opens in your browser. Fonts load from
  Google Fonts, so you need an internet connection to see them.

How to put it online (free options)
  - Netlify:  go to app.netlify.com/drop and drag this whole folder in.
  - Vercel or Cloudflare Pages: create a project and upload the folder.
  - GitHub Pages: push the folder to a repository and turn on Pages.
  Keep index.html and the assets folder together.

What to replace (open index.html in any code editor)
  1. Email: search for  you@example.com  and replace every match
     (the two mailto links, the visible address, and the copy button script).
  2. Text in [square brackets]: your city, bio, projects, jobs, and so on.
  3. Project cards: replace the [SCREENSHOT] boxes with real images, and the
     href="#" links with your project URLs.
  4. GitHub, LinkedIn and resume links: search for  github.com  and
     linkedin.com  in the contact section.
  5. Accent color: change  --sig: #FF5B2E  near the top of the style block.
     Good alternatives: #5EE6FF, #B9A4FF, #E8FF59.
  6. Page title and description: edit the title and meta description in the
     head, so search results show your details.

Notes
  - The orange portrait look comes from CSS (grayscale photo blended onto the
    accent color). To show the photo in natural color, delete
    "filter: grayscale(1) contrast(1.1); mix-blend-mode: multiply" and
    "filter: grayscale(1) contrast(1.12); mix-blend-mode: multiply" from the
    two img tags.
  - Animations switch off automatically for visitors who set "reduce motion".
